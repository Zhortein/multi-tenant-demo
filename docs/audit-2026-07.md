# Demo Application Technical Audit — July 2026

## Executive summary

The demo exposes a broad set of journeys—tenants, products, documents, notifications, email, and Messenger—but it is not yet an automated validation application for the bundle. It originally contained no application test cases, its CI disables migrations, Doctrine validation, and PHPUnit, its documentation uses obsolete configuration, and no effective access rules protect the advertised screens.

Health status: **red-amber as a regression reference** and **amber as a demonstration prototype**.

## Security risks

Resolved on 2026-07-31: form authentication now uses globally unique e-mail identifiers, inactive accounts are rejected, tenant routes require an explicit account-to-path tenant match, and platform administration requires an explicit `ROLE_ADMIN`. Deterministic Tenant A, Tenant B, and administrator fixtures run in CI, and functional tests prove anonymous redirects, successful authentication, authorized access, cross-tenant denial, tenant non-enumeration, and administrator access.

Remaining security validation belongs to milestone 2: downloads and identifier-based lookups must prove current-tenant ownership independently of URL structure, and the integration journeys must retain the same authorization boundary.

## Gaps relative to the bundle

The demo does not automatically exercise alternative resolvers, RLS, multi-database mode, the test kit, tenant-aware caching, or observability. It reimplements tenant-aware services without clearly exposing the boundary with bundle services. It should become the consumer test for every stable public API and test either a selected commit during development or a stable tag.

## Recommendations and effort

Align PHP, Symfony, Doctrine, and resolver configuration first. Make dependency installation immutable, then enable migrations, schema checks, and PHPUnit in CI. Add a focused end-to-end suite prioritizing cross-tenant denials and authorization boundaries.

Qualitative effort: **large, approximately 4–7 person-weeks**, depending on prior stabilization of the bundle API.
